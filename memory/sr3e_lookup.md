# Shadowrun 3rd Edition Lookup Guide

## How to Query Rules

### Quick Search Commands (for Herrick)

When you ask me a question like:
- "What is the essence cost for cyberware?"
- "How does damage resistance work?"
- "What skills are available for vehicles?"

I'll search my SR3E index and return relevant excerpts with page references.

### Search Limitations

- **Best for:** Specific rule lookups, terminology definitions, mechanics explanations
- **Not ideal for:** Narrative worldbuilding questions (use MEMORY.md or daily notes)
- **Response format:** I'll quote the relevant section + page number from the original PDF
